* 문서 버전: v1.0
* 작성 기준일: 2026년 7월 21일
* 초기 운영 지역: 서울·경기
* 초기 등록 목표: 탐정사무소 약 100곳
* 개발·운영 인원: 1인
* 초기 서비스 유형: 탐정사무소 정보 디렉터리
* 초기 핵심 고객: 외도·가족 문제 등을 가진 개인 고객

---

# 1. 프로젝트 개요

## 1.1 서비스 정의

서울·경기 지역에서 외도·가족 문제 등으로 탐정사무소를 찾는 개인 고객에게 업체 정보를 제공하고, 적합한 업체를 탐색한 뒤 직접 전화할 수 있도록 연결하는 정보 플랫폼입니다.

초기에는 플랫폼이 사건 내용을 접수하거나 계약을 중개하지 않습니다.

### 초기 서비스 흐름

```text
사용자 검색
→ 지역·업무 분야별 업체 탐색
→ 업체 상세 정보 확인
→ 전화·홈페이지·지도 버튼 선택
→ 사용자가 업체와 직접 상담
```

### 서비스 한 줄 설명

> 지역과 업무 분야에 따라 탐정사무소를 찾고, 공개적으로 확인된 업체 정보를 비교할 수 있는 탐정사무소 정보 플랫폼

---

## 1.2 해결하려는 문제

### 사용자 문제

탐정사무소를 찾으려는 사용자는 다음과 같은 어려움을 겪을 수 있습니다.

* 어느 업체가 실제 운영 중인지 알기 어렵습니다.
* 업체별 업무 분야를 비교하기 어렵습니다.
* 홈페이지 정보가 오래됐는지 알 수 없습니다.
* 민간자격, 경력, 협회 가입 등의 의미를 구분하기 어렵습니다.
* 광고성 문구와 객관적인 업체 정보를 구분하기 어렵습니다.
* 어떤 상황에서 탐정, 경찰, 변호사에게 문의해야 하는지 판단하기 어렵습니다.
* 업체마다 설명 방식이 달라 비교 기준이 없습니다.

### 업체 문제

탐정사무소 입장에서는 다음과 같은 문제가 있습니다.

* 검색광고 이외의 온라인 유입 경로가 제한적입니다.
* 홈페이지를 운영하더라도 실제 조회 성과를 파악하기 어렵습니다.
* 사용자가 업체의 전문 분야를 정확히 이해하기 어렵습니다.
* 소규모 업체는 SEO와 콘텐츠 제작 역량이 부족할 수 있습니다.
* 공개 정보가 오래됐거나 잘못 표시돼도 직접 수정하기 어렵습니다.

---

## 1.3 플랫폼의 핵심 가치

### 사용자에게 제공하는 가치

* 지역과 업무 분야에 따른 탐색
* 출처가 표시된 업체 정보
* 최종 정보 확인일
* 업체별 정보 비교
* 의뢰 전 확인사항 안내
* 광고와 일반 정보를 구분한 결과
* 업체 정보 정정 요청 경로

### 업체에 제공하는 가치

* 별도 홈페이지 개발 없이 업체 정보 노출
* 지역·업무 분야 검색 유입
* 업체 페이지 조회 통계
* 전화·홈페이지·지도 버튼 클릭 통계
* 업체 정보 직접 수정
* 업체가 제공한 추가 정보 노출
* 광고 상품을 통한 추가 노출

# 2. 사업 방향

## 2.1 초기 포지셔닝

초기에는 다음과 같은 서비스가 아닙니다.

* 탐정 의뢰 중개 서비스
* 사건 접수 서비스
* 조사 계약 서비스
* 견적 비교 서비스
* 탐정업체 평가·순위 서비스
* 결제 플랫폼

초기 포지셔닝은 다음과 같습니다.

> 검증 가능한 공개 정보를 기반으로 한 탐정사무소 전문 디렉터리

이 포지셔닝은 플랫폼이 직접 사건 내용과 민감정보를 보관하지 않으면서 사용자 수요와 업체 반응을 검증하는 데 목적이 있습니다.

---

## 2.2 장기 확장 방향

```text
정보 디렉터리
→ 업체 정보 직접 관리
→ 스폰서 광고
→ 이메일 문의
→ 플랫폼 채팅
→ 복수 업체 견적
→ 기업 고객 서비스
```

### 전화 연결 정책

전화 버튼은 다음 목적으로만 사용합니다.

* 사용자 편의 제공
* 업체에 대한 관심도 측정
* 업체별 페이지 성과 분석
* 광고 상품의 참고 지표

전화 버튼 클릭 또는 전화 연결 자체에 대해 업체나 사용자에게 비용을 청구하지 않습니다.

# 3. 목표 고객

## 3.1 초기 핵심 고객

### 주요 고객군

* 배우자 외도가 의심되는 사용자
* 가족 문제의 사실관계를 확인하려는 사용자
* 연락이 끊긴 가족이나 지인을 찾으려는 사용자
* 개인 사기 피해 사실을 확인하려는 사용자
* 스토킹·학교폭력 등으로 사실 확인이 필요한 사용자
* 휴대전화·저장장치 관련 디지털포렌식 업체를 찾는 사용자

### 고객 특성

* 모바일 검색 비중이 높을 가능성이 큼
* 심리적으로 급하거나 불안한 상태일 수 있음
* 개인정보 노출에 민감함
* 전문 용어에 익숙하지 않음
* 여러 업체를 장시간 비교하기보다 빠르게 상담하고 싶어 함
* 가격보다 신뢰와 비밀 유지 여부를 중요하게 볼 수 있음

## 3.2 보조 고객

* 탐정사무소 운영자
* 탐정사무소 온라인 마케팅 담당자
* 디지털포렌식 업체
* 행정사·변호사 등 인접 분야 사업자
* 향후 기업 조사 담당자

---

## 3.3 대표 사용자 페르소나

### 페르소나 A: 긴급 탐색형

* 30~50대
* 배우자 문제로 빠르게 업체를 찾고 있음
* 모바일로 지역 기반 검색
* 업체 2~3곳을 확인한 뒤 바로 전화
* 후기보다 업체 소개, 지역, 상담 가능 여부를 중요하게 봄

### 페르소나 B: 신중 비교형

* 조사 의뢰가 처음임
* 불법 여부와 비용을 먼저 검색
* 관련 가이드 콘텐츠를 읽은 뒤 업체를 탐색
* 업체의 사업자 확인 상태와 정보 확인일을 중요하게 봄

### 페르소나 C: 업체 운영자

* 자신의 업체가 플랫폼에 등록됐음을 이메일이나 검색으로 인지
* 정보가 정확한지 확인
* 업체 페이지 직접 관리 신청
* 조회·클릭 성과 확인
* 향후 스폰서 광고를 검토

## 정렬 기준

초기에는 다음 정렬만 제공합니다.

* 기본순
* 최근 정보 확인순
* 업체명순

`추천순`, `인기순`, `신뢰순`은 기준이 충분히 정립되기 전까지 사용하지 않습니다.

### 기본순 산정 원칙

기본순은 다음을 조합할 수 있습니다.

* 검색 조건 관련성
* 정보 완성도
* 최근 확인 여부
* 업체 직접 관리 여부
* 무작위 순환 요소

광고 상품은 일반 정렬 결과에 섞지 않고 별도의 스폰서 영역으로 분리합니다.

# 8. 업체 정보 확인 체계

## 8.1 강한 단일 인증 뱃지를 사용하지 않는 이유

사업자등록 상태나 연락처를 확인했다고 해서 업체의 조사 품질, 준법성, 계약 이행까지 보증할 수는 없습니다.

따라서 다음과 같은 포괄적 표현은 사용하지 않습니다.

* 검증된 탐정
* 믿을 수 있는 업체
* 안전 인증
* 우수 업체
* 공식 탐정
* 국가공인 탐정

객관적인 근거 없이 우량하거나 유리하다고 표현하거나 사실보다 부풀리는 표시·광고는 규제 대상이 될 수 있으므로, 플랫폼의 확인 범위를 실제 확인한 항목으로 제한해야 합니다.

---

## 8.2 세분화된 확인 표시

### 사업자 상태 확인

확인 내용:

* 사업자등록번호 상태
* 계속·휴업·폐업 여부

확인하지 않는 내용:

* 서비스 품질
* 대표자 신뢰도
* 조사 방식의 합법성
* 계약 이행 능력

### 연락처 확인

* 해당 전화번호로 업체와 연락 가능함을 확인

### 공식 홈페이지 확인

* 업체가 운영한다고 확인된 홈페이지

### 업체 직접 관리

* 업체 담당자가 해당 페이지에 접근해 정보를 관리

### 최근 정보 확인

* 플랫폼 또는 업체가 주요 정보를 최근 다시 확인

# 9. 데이터 수집 정책

## 9.1 기본 원칙

* 업체 전체 홈페이지를 복제하지 않음
* 필요한 최소 사실정보만 수집
* 경쟁 디렉터리의 데이터를 원천 데이터로 사용하지 않음
* 공식 홈페이지 또는 업체 직접 제출 정보를 우선
* 소개 문구와 사진은 무단 복제하지 않음
* 필드마다 출처와 확인일을 저장
* 삭제·정정 요청 경로 제공
* 자동 수집 결과는 즉시 공개하지 않음

개인사업자의 개인 휴대전화나 개인 이메일 등 자연인과 연결되는 정보는 개인정보에 해당할 수 있습니다. 공개된 정보라도 플랫폼의 목적과 필요한 범위, 정보주체에게 발생할 수 있는 불이익 등을 검토해야 하며, 개인정보 처리 시에는 안전조치도 적용해야 합니다.

다른 플랫폼이 구축한 업체 목록이나 설명을 대량으로 복제하는 방식은 피해야 합니다. 저작권법은 데이터베이스 제작자에게 데이터베이스의 전부 또는 상당 부분을 복제·배포·전송할 권리를 인정합니다.

---

## 9.2 출처 우선순위

```text
1순위: 업체가 직접 제출한 정보
2순위: 업체 공식 홈페이지
3순위: 정부·공공기관 공식 조회 정보
4순위: 업체 공식 SNS
5순위: 기타 공개 정보
```

### 원천으로 사용하지 않는 대상

* 경쟁 업체 디렉터리
* 네이버·구글 사용자 리뷰
* 블로그 후기
* 커뮤니티 게시물
* 출처를 확인할 수 없는 광고
* 다른 플랫폼이 작성한 업체 소개

# 10. 자동 수집 및 갱신 시스템

## 10.1 목적

자동화 목적은 새로운 업체를 무제한으로 긁어오는 것이 아니라 다음에 있습니다.

* 등록 업체 정보의 변경 감지
* 폐쇄된 홈페이지 감지
* 전화번호·주소 변경 후보 탐지
* 장기간 확인하지 않은 업체 탐지
* 운영자의 반복 확인 작업 축소

---

## 10.2 수집 구조

```text
수집 대상 관리
→ 스케줄 실행
→ 원본 페이지 요청
→ 콘텐츠 저장 또는 해시 생성
→ 필드 추출
→ 정규화
→ 기존 데이터 비교
→ 변경 후보 생성
→ 관리자 검수
→ 승인
→ 운영 데이터 반영
→ 관련 페이지 캐시 갱신
```

---

## 10.3 권장 기술

### 웹 애플리케이션

* Next.js
* TypeScript
* PostgreSQL

### 수집 작업

* Python
* httpx 또는 requests
* BeautifulSoup
* Playwright는 필요한 사이트에 한해 제한적으로 사용
* Pydantic
* APScheduler, GitHub Actions 또는 AWS EventBridge

수집 코드까지 TypeScript로 통합할 수도 있지만, 사용자의 Python 데이터 처리 경험과 향후 정규화 작업을 고려하면 Python 배치 프로그램을 별도로 두는 편이 효율적입니다.

# 12. SEO 및 AI 검색 대응

## 12.1 렌더링 전략

### ISR 적용

* 메인
* 업체 상세
* 지역별 페이지
* 업무 분야별 페이지
* 가이드 콘텐츠

### 동적 서버 렌더링

* 다양한 필터가 조합된 검색 결과
* 관리자 화면
* 향후 업체 대시보드

### 클라이언트 컴포넌트

* 전화 버튼 클릭
* 필터 조작
* 공유 버튼
* 관리자 입력 폼
* 통계 차트

Next.js App Router의 페이지와 레이아웃은 기본적으로 Server Component이며, 클릭 이벤트나 브라우저 API가 필요한 영역만 Client Component로 분리할 수 있습니다. ISR 페이지는 데이터 변경 후 `revalidatePath` 등을 사용해 무효화할 수 있으며, 다음 요청에서 새로운 페이지가 생성돼 캐시됩니다.

---

## 12.2 색인 대상

### 색인

* 업체 상세
* 핵심 지역 페이지
* 핵심 업무 분야 페이지
* 품질 기준을 충족한 지역×업무 페이지
* 가이드 콘텐츠

### 색인 제외

* 내부 검색 결과
* 정렬만 다른 URL
* 페이지 번호 외 중복 필터
* 업체가 없는 지역
* 고유 콘텐츠가 없는 조합 페이지
* 관리자 화면
* 수정 요청 화면

Google은 검색·정렬·필터로 무한히 생성될 수 있는 URL의 크롤링을 관리하고, 중복 페이지에는 canonical 등의 정책을 적용할 것을 안내합니다.

---

## 12.3 URL 원칙

* 영문 소문자
* 짧고 일관된 경로
* 영구적인 업체 슬러그
* 지역 코드와 표시명을 분리
* 업체명 변경 시 기존 URL 리다이렉트
* 추적 파라미터는 canonical에서 제외

# 17. 업체 확보 전략

## 17.1 초기 등록

플랫폼이 공개 정보를 기준으로 서울·경기 업체 약 100곳을 등록합니다.

### 등록 기준

* 실제 운영 홈페이지 또는 영업 정보 확인
* 대표 연락처 확인 가능
* 서울·경기 주소 또는 서비스 지역 확인
* 최소 한 개 이상의 업무 분야 확인
* 출처 저장 가능
* 심각한 정보 불일치가 없음

---

## 17.2 업체 접촉 시점

초기 데이터가 충분히 쌓이기 전부터 무작정 영업 메일을 보내지 않습니다.

다음 중 하나를 충족하면 업체에 연락합니다.

* 해당 업체 페이지에 일정 수준의 조회가 발생
* 정보 확인이 필요함
* 업체 정보가 변경된 것으로 보임
* 업체 직접 관리 기능이 준비됨
* 광고 파일럿이 준비됨

---

## 17.3 이메일 유형

### 정보 확인 메일

* 업체 페이지 존재 안내
* 현재 등록 정보 제공
* 오류 수정 링크
* 무료 정보 확인 요청

### 성과 안내 메일

* 검색 노출 수
* 업체 페이지 조회 수
* 전화 버튼 클릭 수
* 홈페이지 이동 수

### 광고 제안 메일

* 스폰서 상품
* 광고 기간
* 표시 위치
* 광고 표시 방식
* 예상이 아닌 실제 통계 중심 설명

영리 목적의 광고성 이메일은 원칙적으로 수신자의 사전 동의, 발신자 정보, 수신거부 방법 등 관련 요건을 고려해야 합니다. 따라서 단순 정보 확인 메일과 광고 영업 메일을 명확히 구분하고, 대량 자동 영업 메일 발송은 법률 검토 후 진행해야 합니다.

> 서울·경기 탐정사무소 약 100곳을 지역과 업무 분야별로 검색할 수 있고, 각 업체의 전화번호·주소·홈페이지·업무 분야·정보 출처·최종 확인일을 확인한 뒤 무료로 전화할 수 있는 모바일 중심 정보 플랫폼입니다. 관리자는 업체 정보와 출처를 관리하고, 변경 후보를 검수하며, 업체별 페이지 조회와 전화·홈페이지·지도 버튼 클릭 데이터를 확인할 수 있습니다.
