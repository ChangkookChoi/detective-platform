# 데이터 수집 정책

## 1. 목적과 범위

탐정사무소의 상호, 공개 사업 연락처, 주소, 업무 분야, 공식 소개 등 디렉터리 제공에 필요한 최소 정보를 수집하고 변경을 감지하기 위한 정책이다. 공개되어 있다는 이유만으로 모든 정보를 수집·재게시할 수 있다고 간주하지 않는다.

## 2. 허용 원칙

- 공식 업체 사이트, 적법하게 이용 가능한 공공 데이터 등 출처가 명확한 자료를 우선한다.
- 출처별 이용약관, robots 지침, 접근 정책, 저작권·데이터베이스 권리와 관련 법령을 검토한다.
- 필요한 구조화 필드만 추출하고 원문 전체 복제를 피한다.
- 개인 휴대전화 등 개인정보일 가능성이 있는 정보는 사업상 공개 연락처인지 검토한다.
- 로그인 우회, CAPTCHA 우회, 접근 통제 회피, 기술적 차단 회피를 하지 않는다.
- 수집 허용 여부가 불명확하면 자동 수집을 보류하고 수동 확인한다.

## 3. 출처 등록

새 출처에는 다음을 기록한다.

- 출처명, 기본 URL, 운영 주체
- 허용된 경로와 필드, 금지된 경로
- 이용약관·robots 확인일과 확인자
- 요청 빈도, 동시성, timeout, 재시도 한도
- 연락 또는 삭제 요청 대응 방법
- 원문/추출 데이터 보존 정책

정책이 바뀌거나 차단 신호가 나타나면 해당 어댑터를 중지하고 재검토한다.

구현상 출처 등록 형식과 실행·중단 절차는 [COLLECTOR_RUNBOOK.md](COLLECTOR_RUNBOOK.md)를 따른다. 설정 파일 검증 통과는 이용약관·robots·법적 허용 검토를 대신하지 않는다.

## 4. 실행 규칙

- Python 3.13과 `uv`로 재현 가능한 환경을 유지한다.
- 명시적 User-Agent와 운영 연락 수단을 제공할 수 있게 한다.
- 합리적인 timeout과 지수형 backoff를 포함한 제한된 재시도를 사용한다.
- 출처별 속도 제한과 낮은 동시성을 적용하고 서버 부하 징후가 있으면 중단한다.
- 동일 페이지를 불필요하게 반복 요청하지 않도록 마지막 수집 시각, ETag, Last-Modified 또는 콘텐츠 해시를 활용한다.
- 각 실행에 작업 ID, 시각, 어댑터/추출기 버전, 결과 건수와 비민감 오류를 기록한다.
- 초기 구현은 출처당 동시성 1, HTTPS와 등록된 host/path만 허용하고 redirect마다 정책을 다시 확인한다.
- connect/read/write/pool timeout을 각각 설정하고 최대 응답 크기를 넘으면 저장 없이 중단한다.
- connect·timeout·일시적 네트워크 오류와 `429`, `500`, `502`, `503`, `504`만 설정된 한도에서 재시도한다. `403`, `404`와 정책 거부는 반복 요청하지 않는다.

## 5. 데이터 처리

- 원본 참조, 수집 시각, 추출값, 정규화값을 구분한다.
- 전화번호, 주소, 상호, 업무 분야는 형식 정규화와 원본 추적을 모두 유지한다.
- 원문 HTML과 이미지의 장기 저장은 기본값이 아니다.
- 추출값은 검수 후보로만 저장하며 공개 운영값을 직접 덮어쓰지 않는다.
- 수집 실패, 404, 출처 삭제는 기존 운영 데이터 삭제로 연결하지 않는다.

## 6. 금지 데이터

- 사용자의 사건 내용, 상담 내용, 조사 대상자 정보
- 통화 내용, 통화 녹취, 통화 상대 식별 정보
- 출처가 의도적으로 공개하지 않은 개인정보
- 계정 자격 증명, 세션 토큰, 유료·제한 콘텐츠 원문
- 서비스 목적과 무관한 대량 프로필 또는 행동 데이터

우발적으로 수집되면 접근을 제한하고 기록된 절차에 따라 삭제·사고 평가를 진행한다.

## 7. 품질과 실패 대응

- 파서 변경은 고정 샘플과 허용된 테스트 페이지로 검증한다.
- 필드 누락률이나 변경률이 임계치를 넘으면 자동으로 검수 우선순위를 높이거나 실행을 중단한다.
- 한 출처의 실패가 다른 출처나 기존 운영 데이터를 손상시키지 않게 격리한다.
- 반복 오류, 차단, 법적 요청은 운영 책임자에게 알리고 원인 해결 전 재시도를 제한한다.

## 8. 삭제·정정 요청

출처 운영자나 업체의 정정·삭제 요청을 받을 경로를 제공한다. 요청자의 권한과 근거를 확인하되 과도한 개인정보를 요구하지 않는다. 법적 의무, 공익, 정보 정확성, 출처 조건을 검토해 공개 중지·수정·삭제 및 수집 제외를 결정하고 감사 이력을 남긴다.
