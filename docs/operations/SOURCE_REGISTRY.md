# 수집 출처 등록부

## 1. 목적

실제 출처의 운영 주체, 공개 경로, 구조, 이용 조건과 robots 확인 결과를 기록한다. 설정 파일이 형식 검증을 통과하거나 `robots.txt`가 허용한다고 해서 저작권·데이터베이스 권리와 관련 법령 검토가 모두 끝난 것으로 보지 않는다.

| `deferred` | 구조 또는 허용 근거가 부족해 자동 수집하지 않음 |
