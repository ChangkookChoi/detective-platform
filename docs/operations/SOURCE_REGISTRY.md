# 수집 출처 등록부

## 1. 목적

실제 출처의 운영 주체, 공개 경로, 구조, 이용 조건과 robots 확인 결과를 기록한다. 설정 파일이 형식 검증을 통과하거나 `robots.txt`가 허용한다고 해서 저작권·데이터베이스 권리와 관련 법령 검토가 모두 끝난 것으로 보지 않는다.

## 2. 등록 상태

| 상태 | 의미 |
| --- | --- |
| `pilot_approved` | 제한된 상세 URL과 사실 필드만 저빈도로 시험 수집 가능 |
| `deferred` | 구조 또는 허용 근거가 부족해 자동 수집하지 않음 |
| `blocked` | 약관·robots·접근 통제 또는 품질 문제로 자동 수집 금지 |

## 3. 등록 출처

### `mugunghwa-detective-official-pilot`

- 상태: `pilot_approved`
- 운영 주체: `탐정사무소 흥신소` 공식 홈페이지의 사업자 표기 운영자
- 정규 출처: `https://xn--mugunghwa-jd13bo06c.com/`
- 설정: [`../../services/collector/sources.toml`](../../services/collector/sources.toml)
- 확인일: 2026-07-23
- 확인자: Codex 보조 조사, 저장소 관리자의 위임 범위
- 정책 확인:
  - 홈페이지는 인증이나 접근 우회 없이 공개되어 있다.
  - 일반 이용약관이나 자동 접근·사실 정보 재사용을 금지하는 문구는 홈페이지에서 확인되지 않았고 개인정보처리방침만 연결되어 있다.
  - 페이지의 저작권 있는 본문·이미지는 수집하지 않고 JSON-LD의 상호, 사업상 공개 대표전화와 주소만 후보로 추출한다.
  - 업체 소개 `description`은 홍보 문구와 저작물 복제 위험을 줄이기 위해 허용 필드에서 제외한다.
- robots 확인:
  - [`robots.txt`](https://xn--mugunghwa-jd13bo06c.com/robots.txt)는 `User-agent: *`, `Allow:/`를 제공한다.
  - 허용 경로는 홈페이지 `/` 하나로 제한한다.
- 구조 확인:
  - 홈페이지는 `ProfessionalService` JSON-LD 한 건에 상호, 대표전화와 `PostalAddress`를 제공한다.
  - 2026-07-23 확인 시 HTTP 200, 최종 URL 동일, 응답 약 37KB였다.
- 실행 제한:
  - 동시성 1, 요청 간격 10초, 최대 2회 시도, 응답 100KB, redirect 1회
  - 명시적 User-Agent와 저장소 이슈 연락 경로 사용
  - 실제 실행 전 robots와 페이지 구조를 다시 확인하고 첫 실행은 개발 DB 한 건으로 제한
- 중단 조건:
  - robots 또는 이용 조건 변경, `403`·`429`, 구조화 데이터 제거·복수 후보화, 사업 연락처 여부 불명확, 운영자 요청

이 등록은 사이트 운영자의 별도 서면 허락을 의미하지 않는다. 단일 공식 페이지의 공개 사실 필드를 검수 후보로만 만드는 기술·운영 파일럿이며, 공개 반영은 별도 관리자 검수를 거친다.

## 5. 재검토

- 파일럿 실행 직전과 운영 예약 실행 도입 전
- robots, 이용약관, 정규 도메인 또는 운영 주체 변경 시
- 90일 이상 정책 확인이 갱신되지 않았을 때
- 정정·삭제 요청이나 차단 신호를 받았을 때

재검토 결과는 확인일·확인자와 함께 이 문서와 설정 파일에 반영한다.
