# SEO 정책

## 1. 목적

검색 사용자가 지역과 업무 분야에 맞는 검증된 업체 정보를 발견하도록 돕되, 얇은 자동 생성 페이지·과장된 주장·광고성 순위로 검색 품질과 사용자 신뢰를 훼손하지 않는다.

## 2. 색인 대상

- 승인·공개 상태이며 고유 정보와 유효한 출처를 가진 업체 상세
- 충분한 업체와 설명을 갖춘 서울·경기 지역 페이지
- 실제 탐색 가치가 있는 업무 분야 및 지역×업무 분야 페이지

검색 결과가 없거나 내용이 거의 같은 조합, 관리자·미리보기·검수 경로, 내부 API, 임시 캠페인 URL은 색인하지 않는다. 필터 조합을 무제한 색인 가능 URL로 만들지 않는다.

## 3. 렌더링과 메타데이터

- 업체명, 지역, 업무 분야, 소개, 확인일 등 핵심 콘텐츠는 서버 생성 HTML에 포함한다.
- 페이지마다 고유하고 사실에 근거한 title과 description을 제공한다.
- canonical URL을 한 가지 형태로 통일한다.
- 공개 상태 변경과 일치하는 sitemap을 제공하고 `lastmod`는 의미 있는 콘텐츠 변경 때만 갱신한다.
- robots.txt는 보안 수단으로 사용하지 않으며 비공개 경로는 인증으로 보호한다.

## 4. URL 규칙

- 안정적이고 읽기 쉬운 slug를 사용한다.
- slug가 바뀌면 기존 URL에서 영구 리디렉션하고 체인을 만들지 않는다.
- 정렬, 추적 파라미터, 빈 필터 조합은 canonical 또는 noindex 정책으로 중복을 제어한다.
- 삭제·폐업 페이지는 정보 가치와 대체 페이지를 검토해 404/410, 유지 안내, 리디렉션 중 적절한 방식을 선택한다.

## 5. 콘텐츠 원칙

- 출처 기반 사실과 운영자가 작성한 요약을 구분하고 타 사이트 원문을 대량 복제하지 않는다.
- `최고`, `1위`, `보장` 등 검증 불가능한 표현을 사용하지 않는다.
- 후기, 별점, 순위가 없는 상태에서 이를 암시하는 제목·구조화 데이터를 만들지 않는다.
- 최종 확인일과 정보 정정 경로를 눈에 띄게 제공한다.
- 지역 페이지는 단어만 바꾼 대량 템플릿이 아니라 실제 업체와 유용한 지역 정보를 제공할 때만 발행한다.

## 6. 구조화 데이터

페이지에서 사용자에게 보이는 사실만 구조화 데이터에 포함한다. 실제 사업 유형에 맞는 Schema.org 타입을 출시 전 검토하고, 주소·전화번호·URL 등 승인된 값만 사용한다. 존재하지 않는 평점, 후기, 가격, 영업시간을 생성하지 않는다.

## 7. 광고와 강화 상품

유료 노출은 `광고`로 명확히 표시한다. 광고 구매가 자연 검색 순위나 품질 보증을 의미한다고 표현하지 않는다. 외부 유료 링크는 검색엔진 지침에 맞는 링크 속성을 사용한다.

## 8. 측정과 점검

- 색인 가능 페이지 수와 실제 승인 업체 수의 이상 차이
- 중복 title/canonical, soft 404, 구조화 데이터 오류
- Core Web Vitals와 모바일 사용성
- 검색 유입 후 상세 조회·전화 클릭(통화 성립으로 해석하지 않음)
- 오래된 확인일을 가진 유입 상위 페이지

SEO 변경은 사람에게 유용한 정보와 데이터 검증 정책을 우선하며, 검색 노출을 위해 미검증 페이지를 공개하지 않는다.

## 9. 현재 구현과 배포 확인

- canonical, `robots.txt`와 `sitemap.xml`의 절대 URL 기준은
  `NEXT_PUBLIC_SITE_URL`에 경로 없는 운영 HTTP(S) origin으로 설정한다. 로컬
  기본값은 `http://localhost:3000`이며 운영 환경에서 그대로 사용하지 않는다.
- 홈, 기본 업체 목록, 공개 업체 상세, 이용 안내, 개인정보 처리방침과 광고
  표시 정책만 sitemap 대상으로 둔다. 업체 상세은 `published` 상태만 조회하며
  최종 검증 시각을 `lastmod`로 사용한다.
- 지역·업무 분야 필터가 적용된 목록은 기본 목록 URL을 canonical로 사용하고
  `noindex, follow`로 둔다. 정정 폼은 `noindex, nofollow`로 둔다.
- 관리자, 내부 API와 로그인 경로는 robots에서 제외하되 실제 보호는 인증과
  권한 검사로 수행한다.
- 업체 상세 JSON-LD는 화면에 표시되는 상호, 대표 전화, 주소와 선택적 소개만
  `LocalBusiness`로 제공한다. 평점, 후기, 가격과 영업시간을 추정하지 않는다.
- 배포 후 실제 운영 URL에서 canonical·robots·sitemap을 확인하고 Rich Results
  Test 또는 Schema Markup Validator로 공개 업체 표본을 재검증한다.
