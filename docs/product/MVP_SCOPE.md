# MVP 범위

## 목적

최소한의 기능으로 사용자가 검증된 탐정사무소 정보를 찾고 무료 전화 연결을 시도하는지, 운영자가 약 100개 업체의 정보를 안전하게 유지할 수 있는지 검증한다.

## 포함 범위

### 공개 사용자 기능

- 서울·경기 업체 목록
- 검수된 사무소 소재지 기준 지역 필터 및 업무 분야 필터
- 업체 상세 페이지
- 업체명, 주소, 전화번호, 업무 분야, 소개 등 승인된 정보 표시
- 정보 출처와 최종 확인일 표시
- 무료 전화 연결 버튼
- 정보 오류 신고·정정 요청 진입점
- 상세 조회와 전화 버튼 클릭의 최소 집계

MVP에서 공개 업체 한 건은 하나의 실제 사무소 또는 지점을 뜻한다. 동일 브랜드의 여러 지점은 주소나 대표 연락처가 다르면 각각 별도 업체 항목으로 등록한다. 업체별 공개 전화번호는 대표 번호 한 개로 제한한다.

### 운영 기능

- 관리자 인증과 권한 제한
- 신규 업체 후보 및 변경 후보 검수 목록
- 원문·수집값·현재 공개값 비교
- 승인, 수정 후 승인, 보류, 반려 및 감사 이력
- 업체 공개, 비공개, 폐업 의심 상태 관리
- 출처 URL과 확인 시각 관리

### 수집기

- Python 3.13과 `uv` 기반 실행 환경
- 허용된 공개 출처에서 필요한 필드만 수집
- timeout, 제한된 재시도, 출처별 요청 빈도 제어
- 정규화와 변경 감지
- 수집값을 검수 대기 데이터로 저장
- 실패가 운영값을 덮어쓰거나 삭제하지 않는 구조

### 수익화 검증

- 광고/강화 상품 노출 영역과 명확한 광고 표시
- 일반 정보와 광고 성과 지표 구분
- 계약·청구는 외부 운영 절차로 처리

## 제외 범위

- 사용자 회원가입, 로그인, 즐겨찾기
- 사건 내용 접수와 조사 대상자 정보 입력
- 실시간 또는 비동기 채팅
- 온라인 결제와 전화 연결 과금
- 후기, 별점, 추천, 품질 점수, 업체 순위
- 통화 연결 성공 추적, 통화 내용, 녹취
- 업체 셀프서비스 가입·정보 수정
- 자동 견적과 복수 업체 매칭
- 서울·경기 밖의 전국 확장
- 복수 서비스 가능 지역 검색, 지도·거리 검색, 업체별 복수 전화번호
- Elasticsearch/OpenSearch, Spring Boot, 마이크로서비스

## 경계 사례

- `무료 전화 연결`은 플랫폼 연결 수수료가 없다는 뜻이며 사용자의 통신 요금까지 보장하지 않는다.
- 광고 업체도 공개 기본 정보와 검수 정책을 동일하게 적용받는다.
- 클릭 수가 많아도 품질이나 추천 순위로 공개하지 않는다.
- 출처에서 업체가 사라져도 즉시 폐업으로 단정하지 않고 검수 후보로 만든다.
- 업무 적법성이나 성과를 확인할 수 없는 홍보 문구는 그대로 보증 표현으로 게시하지 않는다.

## 완료 정의

- 약 100개 목표 데이터셋이 정책에 따라 검수되고 승인된 업체만 공개된다.
- 지역/업무 분야 탐색 → 상세 → 전화 연결 흐름이 주요 기기에서 검증된다.
- 출처와 최종 확인일이 사용자 화면 및 관리자 검수 화면에서 추적 가능하다.
- 신규·변경 수집값이 승인 없이 공개 데이터에 반영되지 않는다.
- 상세 조회와 전화 클릭이 개인정보 없이 중복·봇 트래픽 정책과 함께 집계된다.
- 접근성, SEO, 보안, 백업·복구 및 운영 대응 체크리스트를 통과한다.
